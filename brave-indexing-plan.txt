📌 الخطوة 3 — Web Discovery Project (مجاني — أثر حقيقي)
════════════════════════════════════════════════════════════════

   ما هو: برنامج Brave التطوعي — متصفح Brave يرسل إحصائيات
   تصفح مجهولة تساعد الفهرس في اكتشاف صفحات جديدة.

   ما تفعله أنت:
   1. ثبّت متصفح Brave (brave.com) على جهازك
   2. الإعدادات → Shields & Privacy → Web Discovery Project → فعّل
   3. تصفح موقعك + مواقع مشابهة (دلائل، Reddit، أدوات) بشكل طبيعي
   ← كل زيارة منك (وتصفحك لمواقع يزحفها Brave) تسرّع الاكتشاف

   ⚠️ ملاحظة أخلاقية: لا "تلعب" بالنظام — استخدمه كتصفح طبيعي.
   الاستخدام العادي كافٍ — حتى مشاركة رابطك مع صديق واحد
   يستخدم Brave يحدث فرقًا.

📌 الخطوة 4 — التأكد أن Bravebot يستطيع الزحف (فحص دوري)
════════════════════════════════════════════════════════════════

   تحقق شهريًا (أو اطلب مني):
   • `curl https://bla5k.com/robots.txt | grep -i brave`
     ← لو ظهر "Bravebot Disallow" في أي تحديث مستقبلي لـ Cloudflare
       Managed robots — أبلغني فورًا
   • سيماب حي: curl -I https://bla5k.com/sitemap-0.xml → 200
   • فحص الفهرسة: search.brave.com/search?q=site:bla5k.com
     ← انتظر ظهور "no results" → نتائج

📌 الخطوة 5 — أضف Bravebot صراحةً في robots.txt (اختياري لكن موصى)
════════════════════════════════════════════════════════════════

   إضافة سطر صريح يزيل أي التباس (خاصة بعد تحديثات Cloudflare
   Managed robots التي أضافت Disallow لروبوتات كثيرة):

   User-agent: Bravebot
   Allow: /

   وأيضًا (محرك Brave لاكتشاف الويب):
   User-agent: BraveBot

   → أخبرني وسأضيفه + أنشر (خطوة واحدة)
