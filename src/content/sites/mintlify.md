**Mintlify** has become the go-to documentation platform for modern startups — from Anthropic to Coinbase — with an "AI-native" approach that makes docs readable by both humans and AI agents. In this guide we'll cover what Mintlify is, who builds it, how it works, its AI features, pricing, and how to get started.

## What is Mintlify?

Mintlify is an **AI-native documentation and knowledge platform** — "the knowledge infrastructure agents build on." It's a hosted platform where you write documentation in Markdown (or connect your Git repository) and Mintlify produces a polished, searchable docs site with an AI assistant.

Its distinctive positioning is being **built for AI agents**: the platform includes an MCP server and "agent optimizations" so AI assistants can read and understand your docs — increasingly important as agents become consumers of documentation.

## Who creates Mintlify?

Mintlify is built by **Mintlify, Inc.**, based in San Francisco. It's backed by prominent investors including **Y Combinator and a16z**, and the company reports **20,000+ customers**, 300M+ visitors, and 2B+ agent requests in the past year, with 99.99% uptime. Customers include Anthropic, Coinbase, Amazon, Solana, AT&T, Rivian, and HubSpot.

## How Mintlify works

Mintlify's workflow is built for developer teams:

1. **Write in Markdown** — or connect your Git repository (Git sync).
2. **Mintlify builds the site** — a polished docs site with navigation, search, and an API playground.
3. **Add an AI assistant** — Mintlify's AI (Assistant, Agent, Automations) answers from your docs.
4. **Go live** — custom domain, SEO/GEO/agent optimizations, preview deployments.
5. **Keep it current** — Git sync and Automations keep docs self-updating.

Because it's Git-synced, docs stay in lockstep with your codebase — docs and code never drift far apart.

## Pricing: what does Mintlify cost?

Mintlify's pricing is credit-based for AI features:

- **Starter ($0/month)** — free, includes 10,000 credits/month ($0.01/credit overage); first month of credits free; no credit card.
- **Pro** — for startups and growing teams; includes Agent, Assistant, Automations, preview deployments, and admin APIs (price displayed dynamically — check the site).
- **Enterprise** — custom (contact sales).

AI features are credit-billed (since May 1); there's a 14-day free trial with 5,000 credits.

## Limitations and honest considerations

- **Hosted platform** — not self-hostable except on Enterprise.

## Security and privacy

Mintlify is **SOC 2 certified** with enterprise security features: SSO, SCIM, RBAC, and BYOK. Enterprise plans add EU hosting, self-hosting, audit logs, and custom SLAs. For most teams, the hosted platform with its compliance credentials covers security needs.

3. **Write docs** — in Markdown in the editor or your repo.
4. **Publish** — go live on your domain with an AI assistant.
5. **Automate** — set up Automations to keep docs current.
