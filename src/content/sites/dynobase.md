## What is Dynobase?

Dynobase is a cross‑platform GUI for AWS DynamoDB that uses existing CLI profiles. It lets you view/edit JSON items, build queries with auto‑selection and PartiQL, run JS on results, generate SDK code, and import/export CSV/JSON, supporting offline use.
