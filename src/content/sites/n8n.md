**n8n** is one of the most popular workflow automation platforms in the world — an open-source, fair-code tool that's become especially important in the AI agent era. In this guide we'll cover what n8n is, who builds it, how it works, its AI features, pricing, and how to get started.

## What is n8n?

n8n is an **open-source workflow automation platform** that lets you connect your apps and automate work. It's described as "the world's most popular workflow automation platform for technical teams." You build automations on a **visual canvas** — dragging together integration nodes — and drop into **code** (JavaScript or Python) when you need more power.

Beyond classic automation, n8n has become a serious **AI agent platform**: you can build AI agents with RAG, multi-agent setups, MCP support, and human-in-the-loop approvals, and run them alongside traditional automations.

## Who creates n8n?

n8n is built by the **n8n** company, based in the EU — cloud data is stored in Frankfurt, Germany. The project is "fair-code": source-available with a sustainable license. Its GitHub repository has roughly **199,000 stars** and 200,000+ community members, and it's used by Microsoft, Meta, NVIDIA, Dell, Vodafone, and Mercedes-Benz.

## How n8n works

n8n is built around a visual workflow model:

1. **Start with a trigger** — a schedule, webhook, or app event.
2. **Add nodes** — 500+ pre-built integration nodes connect your apps.
3. **Add logic** — conditions, branches, and code nodes (JS/Python) for control.
4. **Run and debug** — single-step reruns, logs view, and execution debugging.
5. **Deploy** — run on n8n cloud or self-host.

For AI agents, the flow is similar but adds agent nodes: model, tools, memory, and knowledge (RAG) connect into an agent you can converse with.

## Key features of n8n

- **Visual workflow canvas** — build automations visually.
- **JS/Python code nodes** — code when you need it.
- **500+ integrations** — pre-built nodes for popular apps.
- **AI agent builder** — native agent nodes with multi-agent setups.
- **RAG support** — connect knowledge bases to agents.
- **MCP support** — Model Context Protocol for tools.
- **Human-in-the-loop approvals** — human checkpoints in flows.
- **Self-hostable** — Docker, on-prem, full data control.
- **Execution debugging** — single-step reruns and logs view.
- **Git-based version control** — environments and RBAC.
- **SSO SAML/LDAP** — enterprise auth.
- **Audit logs / log streaming** — send logs to SIEM.

## What can you use n8n for?

- **Business automation** — CRM, email, notifications, data sync.
- **AI agents** — build, deploy, and run AI agents.
- **RAG pipelines** — connect documents and knowledge to agents.
- **DevOps automation** — CI/CD, monitoring alerts, incident response.
- **Data pipelines** — move and transform data between apps.
- **E-commerce ops** — orders, inventory, fulfillment.

## Pricing: what does n8n cost?

n8n's pricing is execution-based:

- **Community Edition** — free, self-hosted.
- **Cloud Starter** — 20 EUR/month (2,500 executions).
- **Cloud Pro** — 50 EUR/month (10,000 executions).
- **Business** — 667 EUR/month (40,000 executions, self-hosted).
- **Enterprise** — custom.

All paid plans include **unlimited users, workflows, and steps**; billing is per workflow execution. A startup plan offers 50% off Business.

## Integrations

## Who is n8n for?

n8n is aimed at **technical teams** — developers, engineers, and automation specialists. It's a strong fit for:

- **Engineering teams** building internal automation.
- **Developers** who want code access alongside visual tools.
- **Self-hosters** who want data control.
- **AI builders** creating agent workflows.

It's more technical than consumer no-code tools, which is exactly its strength — and its openness.

## Advantages of n8n

- **Open source / fair-code** — self-hostable, no vendor lock-in.
- **Massive integration library** — 500+ nodes.
- **Code + visual** — the right tool for each job.
- **AI-native** — agents, RAG, MCP built in.
- **EU-based** — cloud data in Frankfurt, GDPR posture.
- **Huge community** — ~199k stars, 200k+ members.

## Limitations and honest considerations

- **Technical focus** — a learning curve for non-technical users.
- **Fair-code license** — source-available, not pure open source (with exceptions).
- **Execution-based pricing** — costs scale with volume.

## Security and privacy

n8n references **SOC 2 and GDPR** and hosts cloud data in the EU (Frankfurt). For maximum control, the **self-hosted Community Edition** keeps everything on your infrastructure. Enterprise features include SSO SAML/LDAP, RBAC, and audit log streaming to SIEM. As with any automation platform, review the data flows you create and who processes what.

## Getting started with n8n

1. **Sign up or self-host** — start the cloud free trial or run the Docker image.
2. **Pick a template** — n8n has templates for common workflows.
3. **Connect apps** — add your integrations.
4. **Build a workflow** — drag nodes, add logic or code.
5. **Test and deploy** — run, debug, and schedule.

A great first project: automate a simple notification or data-sync workflow, then graduate to an AI agent.
