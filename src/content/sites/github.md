## What is GitHub?

GitHub is the world’s largest platform for hosting and collaborating on code. Built
around the Git version-control system, it lets developers store projects, track
changes, review each other’s work, and ship software together.

## Why it matters

- **Version control** — every change is tracked and reversible.
- **Collaboration** — pull requests and issues keep teams in sync.
- **Open source** — millions of public projects to learn from and use.
- **Automation** — built-in CI/CD with GitHub Actions.

## Who is it for?

Whether you’re a beginner pushing your first project or a company running critical
infrastructure, GitHub is the industry standard. It’s also a portfolio — your public
work is visible to employers and collaborators worldwide.

> **Tip:** Star repositories you like to build a personal library of great code.
